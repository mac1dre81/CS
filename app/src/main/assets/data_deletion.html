CredStow Data Deletion

Developer: ThoughtApp App: CredStow • Package: com.credstow.app • Effective: October 2026

CredStow ("the app", "we", "us") is an Android application that securely stores and optionally validates your AI API keys (OpenAI, Anthropic, Google, Hugging Face, etc.).

How to Request Data Deletion

You can delete your data from CredStow using any of the methods below. No account registration is required — all data is stored entirely on your device.

1Delete individual keys within the app
Open CredStow → tap the padlock icon on any key to unlock it → swipe the key to the right to delete it. The encrypted key is permanently removed from your device immediately.
2Clear all app data (recommended for full deletion)
Open your device's Settings → Apps → CredStow → Storage → Clear data.
This deletes all stored keys, settings, preferences, and Pro trial data from your device instantly.
3Uninstall the app
Simply uninstall CredStow from your device. All data is removed.
4Request a Pro refund (optional)
If you purchased Pro and want a refund: open Google Play Store → Menu → Subscriptions & purchases → find your CredStow purchase → Request refund.

Steps 1–3 delete data locally on your device. No server data exists to delete.

Data Deletion Summary

✅ Data that is deleted

  • API keys: All stored API keys (OpenAI, Anthropic, Google, etc.) are encrypted on-device. Deleted immediately via any of the methods above.
  • Key metadata (labels, statuses, expiry dates, sort preferences): Removed when you clear app data or uninstall.
  • Settings (biometric lock, auto-lock timer, font scale, clipboard auto-clear, onboarding state): Removed when you clear app data or uninstall.
  • Pro trial data (trial start/end timestamps): Removed when you clear app data or uninstall.
  • DataStore preferences (purchased product IDs, interstitial ad counters): Removed when you clear app data or uninstall.

⏳ Data that may be retained

Data Type Retention Notes
Purchase records (pro_unlock) Retained by Google Play Managed by Google Play Billing. Request refund through Play Store.
Crash reports Retained by Firebase (90 days) No API keys or user content in crash reports. Auto-deletes after 90 days.
Ad serving events (free tier) Retained per AdMob policy Managed by Google AdMob. Opt out via Ads Settings.
