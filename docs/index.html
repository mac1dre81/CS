Frequently Asked Questions

Everything you need to know about CredStow, security, and privacy.

What is CredStow?
CredStow is a secure Android app by TecMarketa that stores, organizes, and optionally tests your AI API keys (OpenAI, Anthropic, Google Gemini, and 12+ providers) with AES-256-GCM encryption. All data stays on your device — no account or cloud storage required.
Which AI providers are supported?
OpenAI, Anthropic, Google Gemini, OpenRouter, Azure OpenAI, Hugging Face, Cohere, Mistral, Together AI, xAI/Grok, Replicate, and a custom "Other" option. Each provider has its own icon and, where supported, a test endpoint.
Is CredStow free or paid?
CredStow offers a free tier (up to 3 API keys, banner and interstitial ads) and a Pro tier (one-time $4.99 payment) that unlocks unlimited keys, ad-free experience, key testing, encrypted backup, custom sorting, and expiration tracking. A 5-day free Pro trial is available — no credit card required.
Is my data secure and private?
Yes. Your API keys are encrypted with AES-256-GCM and the encryption key is stored in the Android Keystore (hardware-backed where available). No account is required, and we never see, collect, or transmit your keys. No analytics or telemetry is sent to the developer. See our Privacy Policy and Data Deletion pages for full details.
Can I test if my API keys are still valid?
Yes — Pro users can tap "Test key" on any key's detail screen. CredStow sends a minimal request directly to the provider's official API endpoint and reports the status. The key and response are never logged. (Free tier shows status as "Untested".)
What happens if I uninstall the app?
Uninstalling CredStow permanently deletes all keys, metadata, and settings from your device. The encryption keys are destroyed, making recovery impossible. If you use Pro backup/export, make sure to save your encrypted backup before uninstalling.
